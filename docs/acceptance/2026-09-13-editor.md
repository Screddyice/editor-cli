```sh

swift test --package-path native/final-cut-bridge
uvx ruff check src tests scripts
uvx ruff format --check src tests scripts
uv build
uv run editor-cli setup --native-only
uv run editor-cli doctor
uv run python scripts/fcp_live_canary.py --workspace canary-output/new-acceptance
```

Local suites: **572 Python tests and 150 Swift tests passed**. GitHub CI is a
separate check on the pushed PR commit; use the PR Checks tab for current status.
Keep Final Cut in front while running the device canary. Real-footage creative
acceptance and the user's final master export are outside this generated test.
